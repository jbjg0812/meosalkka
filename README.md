# 정비지원 웹사이트

장비 정비 신청(로그인 없음) → 자동 분류 → 분야별 정비인원 처리 → 관리자 현황 조회.
Next.js 15 + TypeScript + Tailwind CSS 4 + SQLite(Prisma 6). 외부 API·CDN을 쓰지 않습니다.

## 로컬 실행

필요: Node.js 20 이상 (권장 22)

```bash
npm install
cp .env.example .env           # 필요 시 관리자 초기 비밀번호 등 수정
npx prisma db push             # prisma/dev.db 생성
npm run db:seed -- --demo      # 관리자 + 키워드 사전 + 테스트 정비인원 계정
npm run dev                    # http://localhost:3000
```

같은 와이파이의 휴대폰에서 확인하려면 `npm run dev -- -H 0.0.0.0` 후 `http://<PC IP>:3000` 접속.

운영 모드: `npm run build && npm start` (`server.mjs`, 기본 포트 3000)

**서버 설치·상시 실행·HTTPS·백업·폐쇄망 이전은 [docs/DEPLOY.md](docs/DEPLOY.md)를 보세요.**

## 구현 단계

- [x] 1단계: 프로젝트 기본 틀, DB 스키마, 로그인·역할별 접근 제어
- [x] 2단계: 정비신청, 접수번호, 진행 조회, 사진 첨부, 도배 방지
- [x] 3단계: 키워드 자동 분류, 키워드 관리
- [x] 4단계: 분야별 게시판, 상세 처리, 미확인 배지·알림
- [x] 5단계: 정비인원 게시판
- [x] 6단계: 관리자 대시보드, 계정 관리, 배포(폐쇄망) 가이드

## 관리자 기능

- **대시보드**: 오늘 접수, 미완료, 미확인(접수 상태), 미분류, 평균 처리시간 / 분야별·상태별 건수 표(숫자를 누르면 해당 목록) / 분야별 평균 처리시간(최근 7일·30일·전체) / 처리 중인 긴급 신청
- **계정 관리**: 계정 추가(임시 비밀번호 자동 생성, 첫 로그인 시 변경), 이름·권한·분야 변경, 비밀번호 초기화, 비활성화(즉시 로그아웃). 본인 잠금·마지막 관리자 해제 방지
- **미분류 / 키워드 사전**: 3단계 참고
- **백업**: `npm run backup`

## 정비인원 게시판

- 글·댓글·사진(최대 3장)·분야 태그(화력/기동/통신/일반/공통)·검색, 정비사례만 보기
- 완료된 신청 상세의 「정비인원 게시판으로 가져오기」: 장비·증상·조치내용·처리기간이 채워진 초안 생성 (신청자 이름·연락처 제외)
- 수정은 작성자, 삭제는 작성자 또는 관리자 (삭제 시 첨부 사진 파일도 삭제)

## 자동 분류 규칙

장비명·증상을 소문자로 바꾸고 공백·하이픈을 제거한 뒤(`K-9 자주포` → `k9자주포`) 사전 키워드 포함 여부를 확인합니다.

1. 장비명에 일치 키워드가 있으면 장비명 일치 수가 가장 많은 분야 (동점이면 증상 일치 수로 결정)
2. 장비명에 없으면 증상 일치 수가 가장 많은 분야
3. 일치 없음 또는 끝까지 동점이면 **미분류** → 관리자 `관리 > 미분류`에 표시

분류를 수동으로 바꾸면 장비명을 사전에 추가할지 묻습니다. 키워드 관리: `관리 > 키워드 사전`.

## 권한·알림

- 조회: 모든 정비인원이 전 분야 게시판·상세 조회 가능 (신청자 연락처 포함)
- 처리(상태 변경·조치내용·답글·분류 변경): 해당 분야 정비인원과 관리자, 미분류 건은 누구나 (`src/lib/permissions.ts`)
- 미확인: 계정 생성 이후 접수되었고 아직 열지 않은 미완료 건. 상세를 열면 확인 처리
- 알림: 화면이 열려 있으면 20초마다 확인해 담당 분야 신규 신청을 화면 상단에 표시.
  `내 정보 > 브라우저 알림 켜기`로 다른 탭에서도 받을 수 있음 (HTTPS 또는 localhost에서만 동작)

## 보안 요약

- 비밀번호 bcrypt 해시, 세션 토큰은 SHA-256 해시로만 DB 저장, httpOnly 쿠키
- 로그인 실패 제한 (계정당 15분 5회, IP당 20회)
- 모든 정비인원/관리자 화면은 서버에서 세션·역할 재확인
- 신청 폼 도배 방지: IP당 10분 5건, 전화번호당 1시간 5건, 숨김 함정 필드, 3초 이내 제출 거부
- 진행 조회: 접수번호 + 전화번호 뒷 4자리 확인 후 서명된 쿠키로 열람, 실패 시 IP당 10분 10회 제한
- 사진: 파일 내용으로 형식 확인(JPG/PNG/WEBP), 장당 5MB·최대 3장, 정비인원만 열람
- 접속 IP 위조 방지: `server.mjs`가 X-Forwarded-For를 실제 접속 IP로 덮어씀 (프록시 뒤에서는 `TRUST_PROXY=true`)
- 만료 세션·오래된 횟수 제한 기록 자동 정리
- CSP로 자기 서버 외 리소스 로드 차단
- HTTPS로 운영 시 `.env`의 `COOKIE_SECURE="true"`
